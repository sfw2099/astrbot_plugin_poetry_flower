# astrbot_plugin_poetry_flower（纵横飞花令）

棋盘拼字飞花令：玩家轮流发送诗句在棋盘上交叉铺字，最终占领格子最多者获胜。

## 依赖

| 插件 | 依赖方式 |
|---|---|
| [astrbot_plugin_poetry_base](https://github.com/sfw2099/astrbot_plugin_poetry_base)（诗词底座） | 库校验、随机开局句、诗句积累。未安装/库未下载时无法开局 |
| [astrbot_plugin_qiuye](https://github.com/sfw2099/astrbot_plugin_qiuye)（秋烨枢纽） | 道具背包/抽道具保底/使用记录。未安装时道具静默跳过 |

## 玩法规则

1. `/纵横飞花令 [宽] [高]` 建局（默认 **21×21**，8~40 可调），系统随机落下首句开局
2. **字数池**：开局随机决定本局允许字数 —— {5,7} 中 1 种（主字数，开局句即用此字数）+ {4,6,8,9,10} 中 2 种，共 3 种；本局所有落子只能用这些字数
3. 发送「**cc 诗句**」落子（需为库中完整诗句、含棋盘上已有的字、向外延伸至少一格）
4. 多个合法落位时发送**金色高亮图**上首尾的数字选择；发送「取消」放弃
5. 交叉点周围一圈会被蔓延占领；最终**占领格子最多者获胜**
6. **自动结束**：棋盘上没有任何可落位的空间时，游戏自动结束并公布战报

## 指令

| 指令 | 说明 |
|---|---|
| 纵横飞花令 `[宽] [高]` | 建局（默认 21×21） |
| `cc 诗句` | 落子（含棋盘已有字、库中完整句、本局允许字数） |
| 数字 | 选择落位（多选项时） |
| 加入 / 退出 / 跳过 | 参与或脱离游戏；跳过需当前玩家超时 |
| 恢复游戏 `[序号]` | 查看存档列表并恢复 |
| 删除存档 `[序号]` | 查看并存档列表并删除 |
| 生成战报 | 当前占地与得分状况 |
| 结束游戏 | 立即清算总分并解散 |
| 诗词道具 文字狱 `<汉字>` | **专属道具**：清除场上所有该字及其周围一圈（清成空白格可重落，领地重算；不受回合限制） |
| 诗词道具 红杏出墙 | **专属道具**：你的下一句可无视棋盘边界（界外部分不显示，一次性） |

> 道具从猜诗句的掉落池与 `/抽道具` 获得，统一存放在秋烨背包（`/我的道具` 查看）。

## 数据布局

```
data/astrbot_plugin_poetry_flower/
  saves/game_{群号}_crossword_{时间戳}.json   # 对局存档（支持恢复）
  crossword_cache_{群号}.png                  # 棋盘渲染缓存
```

## 从旧版迁移（手动）

旧 `astrbot_plugin_poetry_games/saves/` 中的纵横存档（文件名含 `crossword`）可复制到本插件 `saves/` 后用 `/恢复游戏` 恢复——存档结构兼容（旧存档无 `allowed_lens`/`oob_next` 字段时按默认处理）。
